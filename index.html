Beginner workflow

How club members contribute

1

Fork the project

Open the original repository and create a personal fork in your GitHub account.

2

Clone your fork

Copy the repository to your device and start a new branch for your contribution.

3

Add your JSON file

Create a file named after your GitHub username in the participants folder.

4

Commit and open a pull request

Review the diff, push your branch, and open a pull request for maintainer review.
